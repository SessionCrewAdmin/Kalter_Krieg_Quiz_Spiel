# Operation Kalter Krieg V4 – Highscore einrichten

## Was bereits funktioniert
- Namenseingabe am Start
- persönliches Ergebnis am Ende

- lokaler Fallback: Ergebnisse werden im Browser gespeichert
- mehr Cold-War-Look: Ost/West-Farbwelt, Classified-Stempel, Radar, Hot-Line, Alarm bei Kuba, Missions-Freischaltungen, Sounds

## Für eine gemeinsame Klassenrangliste auf allen Geräten: Supabase

1. Kostenloses Projekt auf https://supabase.com anlegen.
2. Im SQL Editor dieses SQL ausführen:

```sql
create table scores (
  id bigint generated by default as identity primary key,
  player_name text not null,
  score integer not null,
  mistakes integer not null default 0,
  best_combo integer not null default 0,
  completed_at timestamptz not null default now()
);

alter table scores enable row level security;

create policy "public insert scores"
on scores for insert
to anon
with check (true);

create policy "public read scores"
on scores for select
to anon
using (true);
```

3. In Supabase: Project Settings > API
   - Project URL kopieren
   - anon/public key kopieren

4. In index.html ganz oben im Script eintragen:

```js
const SUPABASE_URL = "DEINE_PROJECT_URL";
const SUPABASE_ANON_KEY = "DEIN_ANON_KEY";
```

5. index.html wieder in GitHub Pages hochladen.

## Wichtig
Die Rangliste ist dann öffentlich lesbar und Schüler können unter frei gewähltem Namen Ergebnisse eintragen.
Für normalen Unterricht ist das oft ausreichend, aber es ist kein manipulationssicheres Prüfungssystem.


## Punktelegende in V5
Die Startseite zeigt jetzt eine aufklappbare Wertungsübersicht.
- Fehler ziehen keine Punkte ab.
- Fehler werden separat gezählt und setzen die Combo zurück.
- Bei Punktgleichstand entscheidet zuerst die geringere Fehlerzahl, danach die höhere Best-Combo.
